Krok 18a – Archiv historických verzí hry

Uprav projekt Newgame tak, abych mohl v prohlížeči spouštět i předchozí verze hry.
Vytvoř archiv historických verzí podle Git commitů a publikuj je na GitHub Pages na samostatných URL.
- Aktuální verze hry musí zůstat funkční a dostupná na původní adrese.
- Starší verze se nesmí přepisovat při novém nasazení.
- Vytvoř jednoduchou stránku se seznamem dostupných verzí a odkazy na jejich spuštění.
- Každá verze bude mít název, datum a stručný popis změn.
- Historické verze sestav ze skutečných Git commitů, ne z aktuálního kódu.
- Ověř, že se správně načítají všechny soubory a grafika.
- Nepřepisuj ani nemaž současný vývoj projektu.
Zatím připrav archiv všech dostupných předchozích funkčních verzí hry.
